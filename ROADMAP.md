# What's next

## Finish 1.04

The immediate priority is to test the preview, reproduce reported problems, review the Italian wording in context and protect existing saves. Follow-up corrections will receive a new version and their own release notes. Published downloads will not silently change.

## 1.05 — planned, not released

| Area | Intended work |
| --- | --- |
| More languages | Add Spanish, French, German and Korean as contributors and testing become available. Improve English and Italian alongside them. |
| Bug fixes | Investigate reproducible battle, menu and event problems, with a clear check before and after each fix. |
| Performance | Investigate slow scenes and keep optimizations only when measurements show a benefit without breaking the game. |
| Quality of life | Explore clearer stat information, including EV/IV displays, and useful conveniences that fit the game. |
| Guided introduction | Explain the hack's changes and available options inside the game. |
| Battles and progression | Review trainer strategies and progression before proposing balance changes. |

These are directions for development, not promises that every item will ship together. There is no release date yet. New areas or substantial story additions require a separate proposal and review.

To help, [start a discussion](https://github.com/Umberto-DEV/sacred-gold-plus/discussions) about one change, then agree on a small testable contribution. A language will appear in Downloads only when an actual build is available and its testing status is clear.
