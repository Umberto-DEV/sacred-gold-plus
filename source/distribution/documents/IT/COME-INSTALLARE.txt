SACRED GOLD PLUS 1.2.5 - COME INSTALLARE
Edizione italiana | Windows e macOS

INIZIA QUI
Ti servono il tuo file di gioco Pokemon HeartGold (.nds) e UNA sola patch di questo pacchetto. Non devi installare prima Sacred Gold originale o una vecchia versione Plus. La guida spiega anche come aggiornare un gioco Plus esistente. Non serve iniziare una nuova partita.

Percorso rapido per la prima installazione:
1. Estrai lo ZIP e apri la cartella "Sacred Gold Plus 1.2.5".
2. Controlla lo SHA-256 del tuo file HeartGold seguendo il punto 2.
3. Per la ROM originale USA corrispondente scegli Patch > From Clean ROM > US. Per la ROM originale italiana corrispondente scegli Patch > From Clean ROM > IT.
4. In Rom Patcher JS scegli il tuo .nds come "ROM file", il .xdelta nella cartella scelta come "Patch file", poi premi "Apply patch".
5. Controlla il nuovo file (punto 5), poi aprilo nel tuo emulatore DS.

Questo ZIP crea sempre il gioco in ITALIANO, anche partendo da una ROM inglese. Le cartelle US/IT DENTRO Patch indicano la ROM di partenza, non la lingua in cui vuoi giocare. Per ottenere il gioco in inglese scarica invece lo ZIP US.

1. SCARICA, ESTRAI E PREPARA I FILE

Pagina ufficiale dei download:
https://github.com/Umberto-DEV/sacred-gold-plus/releases/tag/v1.2.5
Scegli "Italiano" e scarica Sacred-Gold-Plus-1.2.5-IT.zip. Per giocare in inglese scegli Sacred-Gold-Plus-1.2.5-US.zip. Entrambi funzionano su Windows e Mac. I download automatici "Source code (zip)" e "Source code (tar.gz)" sono per sviluppatori: non sono i pacchetti per giocare.

Windows: in Download fai clic destro sullo ZIP, scegli "Estrai tutto..." e poi "Estrai". Apri la cartella estratta, non l'anteprima dello ZIP compresso.
Mac: fai doppio clic sullo ZIP nel Finder. Se Safari lo ha già estratto, apri la cartella ottenuta. Al suo interno apri "Sacred Gold Plus 1.2.5", poi Come-installare-1.2.5-IT.pdf. Novita-1.2.5-IT.pdf presenta le funzioni attuali del gioco. Entrambi i PDF sono nella cartella principale, subito visibili.

Una ROM è il file del gioco che termina in .nds. Una patch è un file .xdelta con le modifiche: da sola non è un gioco. Un .sav contiene i tuoi progressi. Uno .zip è solo un contenitore compresso. Se la tua ROM è in un archivio, estrai prima il .nds. Non selezionare ZIP, patch o salvataggi al posto della ROM.

Usa una copia ricavata dalla tua cartuccia di HeartGold. Non scaricare ROM piratate: questo progetto non fornisce ROM né link per scaricarle. Se hai solo la cartuccia, crearne un file si chiama "dump". Su un 3DS/2DS già configurato per GodMode9, questa guida spiega come copiare il .nds completo sulla scheda SD e poi sul computer:
https://3ds.hacks.guide/dumping-titles-and-game-cartridges.html#dumping-a-game-cartridge
Leggi i prerequisiti della guida; un normale computer non legge direttamente una cartuccia DS. Conserva intatto il .nds originale, senza ridurne le dimensioni ("trim").

Stai aggiornando? Salva all'interno del vecchio gioco, chiudi completamente l'emulatore e copia ROM e salvataggio corrente in una cartella di backup prima di procedere. Non modificare quella copia di sicurezza.

2. RICONOSCI LA TUA ROM CON LO SHA-256

Lo SHA-256 è un'impronta di 64 caratteri calcolata dal CONTENUTO di un file. Identifica esattamente gioco, regione e revisione. Il nome del file, l'etichetta di un download o la scritta "USA" nel nome non bastano. Rinominare il file non cambia l'impronta e non rende compatibile una ROM diversa.

Dove trovo il MIO SHA? Lo calcoli dal tuo .nds già estratto usando UNO dei metodi qui sotto. Non è un codice stampato sulla cartuccia. Il procedimento è identico per qualsiasi file locale, indipendentemente dal nome o dalla provenienza; un hash non dimostra il possesso o il diritto di usare una copia.

Dove trovo lo SHA ATTESO? In fondo a questa guida, "RIFERIMENTO A - ROM DI PARTENZA" elenca i file supportati e la patch per ciascuno. Prima della patch confronta con quell'elenco. Dopo la patch confronta invece con "RIFERIMENTO B - GIOCO OTTENUTO". È normale che lo SHA iniziale e quello finale siano diversi. Il file separato SHA256SUMS della release serve a verificare gli ZIP scaricati, non la ROM.

Metodo dal browser (senza installare app o scrivere comandi, Windows e Mac):
a. Apri https://emn178.github.io/online-tools/sha256_checksum.html
b. Verifica il titolo "SHA256 File Checksum". Lascia Input Type = File, Output Encoding = Hex e HMAC disattivato.
c. Premi il pulsante per scegliere il file in "Input" e seleziona il tuo .nds, oppure trascinalo in quell'area. Il sito elabora i file locali nel browser senza caricarli su un server.
d. Attendi i 64 caratteri in "Output". Se necessario premi "Hash". Premi "Copy" per copiarli.
e. In questa guida premi Ctrl+F (Windows) o Command+F (Mac), incolla tutto il risultato e cerca la corrispondenza nel Riferimento A. Le lettere maiuscole e minuscole hanno lo stesso significato.

Metodo offline su Mac:
Apri Spotlight (Command+Spazio), cerca Terminale e aprilo. Scrivi quanto segue, con uno spazio alla fine:
  shasum -a 256
Trascina il tuo .nds dal Finder nel Terminale: verrà inserito il percorso completo. Premi Invio. Copia i primi 64 caratteri del risultato, non il nome del file. Il comando legge il file senza modificarlo.

Metodo offline su Windows:
Fai clic destro sul .nds e scegli "Copia come percorso" (in alcune versioni tieni premuto Maiusc mentre fai clic destro). Apri Windows PowerShell dal menu Start. Scrivi il comando sotto sostituendo il percorso di esempio fra gli apici singoli con quello copiato. Togli le virgolette doppie esterne copiate e mantieni gli apici singoli. Se il nome contiene un apostrofo, raddoppialo all'interno degli apici.
  (Get-FileHash -Algorithm SHA256 -LiteralPath 'C:\Giochi\HeartGold.nds').Hash
Premi Invio e copia i 64 caratteri risultanti. Il comando legge il file senza modificarlo. Su Linux puoi usare sha256sum seguito dal percorso del .nds tra virgolette.

Non confrontare SHA-1, MD5 o CRC32 con SHA-256: sono calcoli diversi. Rom Patcher JS mostra quegli altri codici, quindi per questa guida usa uno dei metodi appena descritti.

3. SCEGLI UNA SOLA PATCH

Trova lo SHA-256 identico nel Riferimento A. Il percorso sotto il nome del gioco indica la patch da selezionare. Ogni percorso parte dall'interno di "Sacred Gold Plus 1.2.5"; il simbolo > nelle istruzioni significa "apri la cartella successiva".

HeartGold originale e non modificato è indicato come "Clean ROM" (clean = mai modificata con patch). La copia USA con lo SHA corrispondente usa:
  Patch/From Clean ROM/US/from-clean-us.xdelta
La copia italiana con lo SHA corrispondente usa:
  Patch/From Clean ROM/IT/from-clean-it.xdelta
Una ROM europea in inglese non è automaticamente quella USA. SoulSilver, Sacred Gold di Drayano senza Plus, altre regioni e file ridotti o personalizzati non hanno un percorso supportato se l'intero hash non corrisponde.

Giochi già a Plus? Apri "From Plus" seguito dalla tua versione ATTUALE e dalla sua lingua attuale (US = inglese, IT = italiano). Per 1.01, 1.02 e 1.03 sono verificati solo gli ingressi inglesi, quindi non c'è una cartella IT. Manteniamo la numerazione originale: 1.01, non 1.0.1. La 1.04 distingue anche le varianti della camera; la 1.2.2 distingue le due edizioni. Se non sai quale hai, lo decide lo SHA.

Applica soltanto IL .xdelta corrispondente. Ogni patch porta direttamente alla 1.2.5: non applicare clean, 1.1 e altre patch una dopo l'altra. Non devi scaricare le vecchie release. Se la ROM corrisponde già al Riferimento B, possiedi già questa edizione della 1.2.5 e non devi applicare patch.

4. APPLICA LA PATCH NEL BROWSER

Apri il sito ufficiale Rom Patcher JS:
https://www.marcrobledo.com/RomPatcher.js/
È il metodo consigliato su Windows e Mac: non devi installare un'applicazione. La patch viene applicata localmente nel browser.

a. Resta nella modalità "Apply patch" e lascia "Creator mode" spento.
b. In "ROM file" scegli il .nds di partenza di cui hai controllato lo SHA. Attendi che venga letto.
c. In "Patch file" scegli l'UNICO .xdelta individuato al punto 3. Non selezionare l'intera cartella Patch o manifest.json.
d. In "Settings" lascia "Fix ROM checksum" SPENTO. Chiudi Settings facendo clic all'esterno. Non aggiungere/rimuovere intestazioni e non disattivare i controlli se usi un altro programma.
e. Premi "Apply patch" e attendi il download del nuovo .nds. Potrebbe avere il nome originale seguito da "(patched)". Cercalo nell'elenco Download del browser.
f. Salvalo come NUOVO file. Puoi rinominarlo "Sacred Gold Plus 1.2.5 IT.nds". Mantieni l'estensione .nds e non sovrascrivere la ROM originale o il salvataggio.

Le schermate nel PDF mostrano i campi prima di scegliere i file. I pulsanti per scegliere i file possono seguire la lingua del computer. L'aspetto del sito può cambiare: fai riferimento ai nomi dei campi.

5. VERIFICA IL RISULTATO E GIOCA

Calcola nuovamente lo SHA-256, questa volta del NUOVO .nds. Deve corrispondere esattamente al Riferimento B. Il solo messaggio "patch applicata" o il download riuscito non sono il controllo finale. Se lo SHA è diverso, non sostituire il tuo gioco: leggi Risoluzione dei problemi.

Prima partita: apri il tuo emulatore DS, scegli la funzione Apri/Carica ROM e seleziona il nuovo .nds. La patch e lo ZIP non si possono giocare. Segui la configurazione prevista dall'emulatore: qui non sono inclusi emulatore o BIOS. I cheat sono facoltativi; non servono per installare o giocare.

Aggiornamento con salvataggio: con l'emulatore chiuso, associa una COPIA del salvataggio esistente al nuovo gioco. Molti emulatori collegano i file con lo stesso nome prima dell'estensione, per esempio:
  Sacred Gold Plus 1.2.5 IT.nds
  Sacred Gold Plus 1.2.5 IT.sav
Usa la cartella dei salvataggi prevista dall'emulatore oppure la funzione Importa salvataggio se li gestisce internamente. Un .dsv o un salvataggio gestito dall'app può richiedere importazione/esportazione: cambiare l'estensione non lo converte. Non sovrascrivere il vecchio salvataggio con uno nuovo vuoto.

Avvia normalmente la nuova ROM e scegli Continua. Controlla progressi, squadra, Borsa (compresi gli slot aggiuntivi) e impostazioni Plus, salva nel gioco, chiudi del tutto l'emulatore e riapri con Continua. Non caricare un vecchio savestate/salvataggio rapido dell'emulatore. Se manca Continua, fermati e correggi l'associazione del salvataggio: non iniziare una nuova partita e non azzerare le impostazioni. V.1.2.5 appare nello schermo superiore del titolo e in Opzioni > SELECT > Plus.

Conserva il backup. Salvare con una ROM vecchia può rendere inaccessibili gli slot aggiuntivi della Borsa e impedirne il recupero automatico tornando alla ROM nuova.

RISOLUZIONE DEI PROBLEMI

Nessuna corrispondenza dello SHA iniziale: assicurati di avere calcolato il .nds estratto e non lo ZIP. Controlla se coincide già con il Riferimento B. Altrimenti regione, revisione o modifiche sono diverse. Rinominare il file, scegliere una patch simile o forzare i controlli non risolve. Ricrea una copia completa della tua cartuccia. Puoi anche applicare la patch a quella ROM pulita e associare al risultato il tuo salvataggio Plus esistente.

"Checksum mismatch", "source too short" o errore durante la patch: ricontrolla lo SHA iniziale e il percorso esatto nel Riferimento A. Non disattivare la verifica dei checksum. Se i file corrispondono ma il browser fatica, prova un browser desktop aggiornato o il metodo facoltativo xdelta3 qui sotto.

SHA finale diverso: controlla di aver usato lo ZIP della lingua desiderata e il nuovo file ottenuto, con "Fix ROM checksum" spento e senza applicare altre patch dopo. Estrai nuovamente lo ZIP ufficiale e riparti da un file supportato intatto. Lo SHA finale corrispondente conferma gli stessi byte del gioco, qualunque sia il nome del file.

Serve aiuto? Segnala SHA-256 iniziale, nome dello ZIP, percorso della patch, programma/browser usato e messaggio di errore esatto qui:
https://github.com/Umberto-DEV/sacred-gold-plus/issues
Non caricare ROM o salvataggi.

FACOLTATIVO - XDELTA3 DA RIGA DI COMANDO

Il metodo nel browser basta per chi è alle prime armi. Se usi già la riga di comando, xdelta3 offre un'alternativa offline. Progetto ufficiale e download:
https://github.com/jmacd/xdelta

Su Mac, se hai già Homebrew, esegui "brew install xdelta". Su Windows ottieni xdelta3 dalle release del progetto ufficiale e usa il nome reale dell'eseguibile (può contenere versione o architettura). Se non trovi un eseguibile adatto al tuo computer, usa il metodo nel browser. Apri Terminale/PowerShell nella cartella estratta "Sacred Gold Plus 1.2.5". Sostituisci origine.nds con il percorso completo della ROM controllata e il percorso della patch con quello del Riferimento A. Le virgolette servono se i percorsi contengono spazi.

Esempio Mac (partenza da HeartGold italiana):
  xdelta3 -d -D -R -s "origine.nds" "Patch/From Clean ROM/IT/from-clean-it.xdelta" "patched.nds"
Esempio Windows PowerShell (xdelta3.exe in questa cartella):
  .\xdelta3.exe -d -D -R -s "origine.nds" "Patch/From Clean ROM/IT/from-clean-it.xdelta" "patched.nds"
Scegli un nome nuovo per il file ottenuto. Torna al punto 5 e controllane lo SHA-256.
