SACRED GOLD PLUS 1.2.5 - HOW TO INSTALL
English edition | Windows and macOS

START HERE
You need your own Pokemon HeartGold game file (.nds) and ONE patch from this package. You do not need to install the original Sacred Gold hack or any earlier Plus version first. The steps below also cover updating an existing Plus game. Nothing here requires starting a new game.

Quick route for a first installation:
1. Extract this ZIP and keep the folder "Sacred Gold Plus 1.2.5".
2. Check your HeartGold file's SHA-256 using step 2.
3. For the matching original USA game, choose Patch > From Clean ROM > US. For the matching original Italian game, choose Patch > From Clean ROM > IT.
4. In Rom Patcher JS, select your .nds as "ROM file", the .xdelta inside that folder as "Patch file", then click "Apply patch".
5. Check the new file (step 5), then open it in your DS emulator.

This ZIP always makes the ENGLISH game, even if your starting ROM is Italian. The US/IT folders INSIDE Patch describe the starting ROM, not the language you want to play in. For an Italian result, download the IT ZIP instead.

1. DOWNLOAD, EXTRACT AND PREPARE

Official download page:
https://github.com/Umberto-DEV/sacred-gold-plus/releases/tag/v1.2.5
Choose "English" and download Sacred-Gold-Plus-1.2.5-US.zip. For Italian choose Sacred-Gold-Plus-1.2.5-IT.zip. Both work on Windows and Mac. The automatic "Source code (zip)" and "Source code (tar.gz)" downloads are for developers; they are not the player packages.

Windows: right-click the ZIP in Downloads, choose "Extract All...", then "Extract". Open the extracted folder, not the compressed ZIP preview.
Mac: double-click the ZIP in Finder. If Safari already extracted it, open the resulting folder. Inside, open "Sacred Gold Plus 1.2.5", then How-to-install-1.2.5-EN.pdf. Whats-New-1.2.5-EN.pdf introduces the current game features. Both PDFs are in the main folder, ready to read.

A ROM is your game file ending in .nds. A patch is a smaller .xdelta file describing changes; it cannot run as a game. A .sav contains your progress. A .zip is only a compressed container. If your own ROM is archived, extract the .nds first. Never select a ZIP, patch or save as the ROM.

Use a backup made from your own HeartGold cartridge. Do not download pirated ROMs; this project supplies neither ROMs nor links to ROM downloads. If you only have a cartridge, making a file from it is called "dumping". On a 3DS/2DS already set up for GodMode9, the cartridge-dumping guide explains how to copy an untrimmed .nds to the SD card, then to your computer:
https://3ds.hacks.guide/dumping-titles-and-game-cartridges.html#dumping-a-game-cartridge
Read its prerequisites; a normal computer cannot read a DS cartridge directly. Keep the original .nds untouched.

Updating? Save inside the old game, fully close the emulator, then copy your ROM and its current save to a backup folder before proceeding. Leave that backup alone.

2. IDENTIFY YOUR ROM WITH SHA-256

SHA-256 is a 64-character fingerprint calculated from the CONTENTS of a file. It tells us exactly which game, region and revision you have. The filename, a download label or "USA" in the name is not proof. Renaming a file does not change its fingerprint or make an incompatible ROM work.

Where do I find MY hash? Calculate it from your actual, extracted .nds using ONE of the methods below. It is not a serial number printed on the cartridge. The process is the same for any local file, regardless of its name or origin; a hash does not establish ownership or permission to use it.

Where is the EXPECTED hash? This guide's "REFERENCE A - STARTING ROMS" lists the supported files and the patch to use for each. Before patching, compare with that list. After patching, compare with "REFERENCE B - FINISHED GAME". The before and after hashes are supposed to differ. The release's separate SHA256SUMS file checks the downloaded ZIPs, not your ROM.

Browser method (no app or command required, Windows and Mac):
a. Open https://emn178.github.io/online-tools/sha256_checksum.html
b. Confirm the heading says "SHA256 File Checksum". Keep Input Type = File, Output Encoding = Hex, and HMAC disabled.
c. Click the file chooser in "Input" and select your .nds, or drag it onto that area. The page processes local files in the browser without uploading them.
d. Wait for the 64-character result in "Output". If necessary, click "Hash". Use "Copy" to copy the result.
e. In this guide press Ctrl+F (Windows) or Command+F (Mac), paste the complete result and find its entry in Reference A. Uppercase/lowercase letters mean the same thing.

Offline Mac method:
Open Spotlight (Command+Space), type Terminal, and open it. Type the following, including a space at the end:
  shasum -a 256
Drag your .nds from Finder into Terminal so its full path is inserted, then press Return. Copy the first 64 characters of the result, not the filename. This reads the file without changing it.

Offline Windows method:
Right-click your .nds and choose "Copy as path" (on some Windows versions hold Shift while right-clicking). Open Windows PowerShell from Start. Type the command below, replacing the example path between the single quotes with your copied path. Remove the copied outer double quotes; keep the single quotes. If a filename contains an apostrophe, double it inside the single quotes.
  (Get-FileHash -Algorithm SHA256 -LiteralPath 'C:\Games\HeartGold.nds').Hash
Press Enter and copy the 64-character result. This reads the file without changing it. Linux users can run sha256sum followed by the quoted .nds path.

Do not compare SHA-1, MD5 or CRC32 with SHA-256: they are different calculations. Rom Patcher JS displays those other hashes, so use one of the methods above for this guide.

3. CHOOSE ONE PATCH

Find the exact SHA-256 match in Reference A. The path immediately below that game's name is the patch to select. Every path starts inside "Sacred Gold Plus 1.2.5"; the > signs in these instructions mean "open the next folder".

Original, unmodified HeartGold is called "Clean ROM" (clean = not previously patched). A USA copy matching the USA hash uses:
  Patch/From Clean ROM/US/from-clean-us.xdelta
An Italian copy matching the Italy hash uses:
  Patch/From Clean ROM/IT/from-clean-it.xdelta
An English-language European ROM is not automatically the USA ROM. SoulSilver, Drayano's Sacred Gold without Plus, other regions and trimmed or customized files have no listed route unless their entire hash matches.

Already playing Plus? Open "From Plus" followed by your CURRENT version, then its current language (US = English, IT = Italian). Versions 1.01, 1.02 and 1.03 have only verified English inputs, so there is no IT folder for them. We keep the original numbering, 1.01 rather than 1.0.1. Version 1.04 also separates camera variants; 1.2.2 separates its two editions. If unsure which you have, the hash decides.

Apply only the ONE matching .xdelta. Every patch goes directly to 1.2.5. Do not apply clean, 1.1 and other patches in sequence. You do not need to download older releases. If your ROM already matches Reference B, you already have this edition of 1.2.5 and do not need a patch.

4. APPLY THE PATCH IN YOUR BROWSER

Open the official Rom Patcher JS page:
https://www.marcrobledo.com/RomPatcher.js/
This is the recommended method for Windows and Mac; there is no application to install. It applies the patch locally in the browser.

a. Stay in "Apply patch" mode; leave "Creator mode" off.
b. Under "ROM file", click the file chooser and select the starting .nds whose hash you checked. Wait for it to load.
c. Under "Patch file", choose the ONE .xdelta from step 3. Do not choose the whole Patch folder or manifest.json.
d. In "Settings", leave "Fix ROM checksum" OFF. Close Settings by clicking outside it. Do not add/remove headers or bypass validation if another patcher offers those options.
e. Click "Apply patch" and wait until your browser downloads a new .nds. It may be called the original name with "(patched)" added. Look in your browser's Downloads list.
f. Save it as a NEW file. You may rename it "Sacred Gold Plus 1.2.5 EN.nds". Keep the .nds extension and do not overwrite your original ROM or save.

The PDF's screenshots show the fields before any files are selected. File-chooser wording may follow your computer's language. The website layout can change; the field names are the useful reference.

5. VERIFY THE RESULT AND PLAY

Calculate SHA-256 again, this time for the NEW .nds. It must match Reference B exactly. A successful download or "patch applied" message alone is not the final check. If it differs, do not replace your existing game: see Troubleshooting below.

First play: open your DS emulator, choose its Open/Load ROM option, and select the new .nds. A patch file and the ZIP cannot be played. Use your emulator's own setup instructions; this package includes no emulator or BIOS. Cheats are optional and are not required to install or play.

Updating a save: keep the emulator closed while associating a COPY of your existing save with the new game. Many emulators pair files by matching the name before the extension, for example:
  Sacred Gold Plus 1.2.5 EN.nds
  Sacred Gold Plus 1.2.5 EN.sav
Use the emulator's expected save folder or its Import Save option if it manages saves internally. A .dsv or app-managed save may need that import/export function; changing its extension does not convert it. Do not let a blank new save overwrite your old one.

Start the new ROM normally and choose Continue. Check your progress, party, Bag (including extra slots) and Plus settings, save inside the game, close the emulator fully, and reopen using Continue. Do not resume an old emulator savestate/quick save. If Continue is missing, stop and fix the save association; do not start a new game or reset settings. Version V.1.2.5 appears on the upper title screen and in Options > SELECT > Plus.

Keep your backup. Saving with an older ROM can lose access to expanded Bag slots and prevent their automatic recovery when you return to the newer ROM.

TROUBLESHOOTING

No matching starting hash: confirm you hashed the extracted .nds, not the ZIP. Check whether it already matches Reference B. Otherwise your region, revision or modifications differ. Renaming it, choosing a similar patch or forcing a checksum override will not fix that. Make a fresh untrimmed backup of your own cartridge. You can also patch that clean backup to 1.2.5 and associate your existing Plus save with the result.

"Checksum mismatch", "source too short" or a patching error: recheck the starting hash and the exact patch path from Reference A. Do not turn off checksum validation. If the files match but your browser struggles, try a current desktop browser or the optional xdelta3 method below.

The output hash differs: confirm you used the correct edition ZIP, selected the new output file, kept "Fix ROM checksum" off, and did not apply another patch afterwards. Re-extract the official ZIP and retry from an untouched supported source. A matching output hash proves the same game bytes, regardless of the filename.

Need help? Report the starting SHA-256, ZIP name, patch path, patcher/browser and exact error at:
https://github.com/Umberto-DEV/sacred-gold-plus/issues
Do not upload your ROM or save.

OPTIONAL - XDELTA3 FOR COMMAND-LINE USERS

The browser method above is sufficient for beginners. If you already use command-line tools, xdelta3 provides an offline alternative. Official project and downloads:
https://github.com/jmacd/xdelta

On Mac with Homebrew already installed, run "brew install xdelta". On Windows obtain xdelta3 from the official project's releases and use the actual executable filename (it may include a version or architecture). If no executable suits your computer, use the browser method. Open Terminal/PowerShell in the extracted "Sacred Gold Plus 1.2.5" folder. Replace source.nds with the full path to your checked ROM and the patch path with the one from Reference A. Quotes are necessary around paths containing spaces.

Mac example (original USA source):
  xdelta3 -d -D -R -s "source.nds" "Patch/From Clean ROM/US/from-clean-us.xdelta" "patched.nds"
Windows PowerShell example (xdelta3.exe in this folder):
  .\xdelta3.exe -d -D -R -s "source.nds" "Patch/From Clean ROM/US/from-clean-us.xdelta" "patched.nds"
Use a new output filename. Return to step 5 and verify its SHA-256.
