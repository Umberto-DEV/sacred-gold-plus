INSTALLATION 1.2.5

1. Close the game and back up your current save before replacing the ROM.
2. Calculate your source ROM SHA-256. Match the exact entry below; filenames are not sufficient. Modified, customized, trimmed or unrecognized revisions are not accepted.
3. Open Rom Patcher JS (https://www.marcrobledo.com/RomPatcher.js/) or xdelta3. Select the ROM and the matching patch. Write a new output file and check its target SHA-256.
4. Associate the existing .sav with the new ROM using the basename expected by your emulator. Do not overwrite it with a new save. Start from Continue, not an older emulator quick state.

xdelta3 example (replace the filenames):
  xdelta3 -d -D -R -s "source.nds" "Patch/from-clean-us.xdelta" "Sacred Gold Plus 1.2.5 EN.nds"

SHA-256 tools: macOS shasum -a 256; Linux sha256sum; Windows PowerShell Get-FileHash -Algorithm SHA256.

This ZIP produces English from every listed input, including Italian inputs. Download the IT ZIP to produce Italian. The ZIP language is the output language.
