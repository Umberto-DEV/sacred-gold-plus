SACRED GOLD PLUS 1.2 — ENGLISH


This is the English download of version 1.2. It holds the patch, the
recommended cheats, the manuals, the licence and the instructions. It
does not hold the game: the patch has to be joined to your own game
file, which you must obtain lawfully.

There is one version of 1.2 per language. The camera is the Plus one,
and indoors it is native in eight maps. HeartGold's original camera is
still available everywhere as an optional cheat.

1.2 contains everything 1.1 contained: it is built from the finished
1.1, not beside it.


WHERE TO START

Open HOW-TO-INSTALL.txt and follow the steps. In short: back up the game
and the save, pick from the Patch folder the file that matches the
version you already have, and join it to the game with one of the
programs listed there.

Then read WHATS-NEW-1.2.txt: it explains the five new options-page
features and how to switch them on.


WHAT IS IN THIS DOWNLOAD

README.txt
    This file.

HOW-TO-INSTALL.txt
    How to join the patch to the game, with three different programs. It
    carries the fingerprints to check and the list of things not to do.

WHATS-NEW-1.2.txt
    What changed since 1.1 and 1.04, written for players: the options
    page, the indoor camera, the online services, the text corrections,
    saves and cheats.

Patch/
    The differences between your game and the English 1.2. Five files,
    one for each recognized starting version, plus manifest.json with
    sizes and fingerprints. They are not games and they do not open in
    an emulator.

Cheats/
    The optional codes for melonDS, in both formats, plus a note saying
    when they are needed and when they are not. Every code starts off.

Manual/
    The five original Sacred Gold / Storm Silver PDF guides, the trainer
    reference and the game guide. ABOUT-THESE-GUIDES.txt says how far
    they can be trusted for 1.2.

LICENSE.txt
    The terms of this project's own tools (GPL-3.0-or-later). Third
    party rights are named in the credits below.

The ZIP is not a playable game, and opening it applies no patch.


WHAT IS NOT HERE

- The game. This project distributes no ROM.
- An emulator. melonDS is downloaded and updated on its own.
- Patches towards the older versions (1.03, 1.04, 1.1). They stay on the
  earlier release pages. Only 1.2 is here.
- The patching programs. They belong to other authors and must be taken
  from their official sites; the addresses are in HOW-TO-INSTALL.txt.


WHAT THIS RELEASE DOES NOT CLAIM

- It does not claim a completed playthrough. Testing is limited and
  almost all of it was done on a computer with an emulator, not on
  hardware.
- It does not claim that a save from an earlier version holds up for a
  whole playthrough.
- It claims nothing about a real Nintendo DS.
- It does not claim that the third-party cheat catalogue works.
- It does not claim that every 1.2 addition has been watched running:
  WHATS-NEW-1.2.txt says, item by item, which ones have.
