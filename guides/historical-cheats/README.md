# Historical cheat references

These two documents are preserved unchanged from the original Sacred Gold Plus 1.03 package:

- [Action Replay Codes.pdf](Action%20Replay%20Codes.pdf): the earlier Sacred Gold / Storm Silver reference guide.
- [Cheat Codes.txt](Cheat%20Codes.txt): the cheat notes distributed with Plus 1.03.

**Compatibility with the current 1.04 has not been established for every code in these documents.** Recommendations and compatibility claims inside the originals describe their authors' earlier work. The TXT itself expresses doubts about compatibility with the older SG/SS guide and about one animation code. Keep those limitations in mind.

The Game IDs printed in the PDF belong to the older Sacred Gold / Storm Silver editions. They do not identify the current Plus releases. In that guide, **Classic** means an older SG/SS edition; it does not mean the **Normal Angle** camera option in Plus 1.04. Use the identity of your actual game file when configuring an emulator; a matching name or ID alone does not establish that a code works.

The current downloads include a separate seven-code selection with targeted checks and IT/US labels; see the [cheat instructions](../../PLAY.md#optional-cheats). These original documents remain historical references. Downloading them does not install or enable cheats, and they do not describe the state of your emulator. Before experimenting, preserve an untouched game and normal-save backup. Start with cheats off and test one code at a time on a separate copy. The historical speedup descriptions do not establish a measured frame-rate improvement for 1.04.
